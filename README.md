# 🚀 Striver's A2Z DSA Sheet - Java Solutions

Welcome to my **Data Structures & Algorithms journey!** 👋

This repository contains my **daily Java solutions** for [Striver's A2Z DSA Sheet](https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z).

I am solving the sheet **consistently from basics to advanced**, understanding each problem, writing the solution in Java, and uploading my progress to GitHub.

The goal is to build strong **problem-solving, Data Structures & Algorithms, and coding interview skills** through consistent practice.
